## 1. Постановка задачи

Моделирование катастрофического схода ледника Колка (Кавказ, Северная Осетия, 20 сентября 2002 г.) в web-приложении r.avaflow. Первый тестовый запуск показал нереалистичное поведение: ледник **растекался в стороны** вместо движения по долине Геналдон.

### Натурные данные события (Evans et al., 2009)
| Параметр | Значение |
|----------|---------|
| Объём отрыва | ~130 млн м³ (3/4 массы ледника) |
| Длина пробега | 19.2 км |
| Средний уклон | 6° |
| Максимальная скорость | 65–80 м/с |
| Средняя скорость | ~50 м/с |
| Время движения | ~390 с |
| Толщина ледника | 85–175 м |
| Жертвы | 125 человек |

## 2. Анализ первого запуска

### 2.1. Параметры первого запуска

```bash
r.avaflow -e prefix=kolka01 cellsize=30 phases=s,fs,f \
  elevation=elev hrelease1=hent1 hrelease2=hent2 \
  density=2700,1300,1100 time=60,600
```

Все остальные параметры — дефолтные v3:
- `friction=35,20,0,0,0,0,0.05` (phi1=35°, delta1=20°)
- `controls=0,0,1,0,0,0,0,0,0,2,0` (entrainment выключен)
- `basal=-7.0,0.0`
- `special` = 33 дефолтных значения

## 3. Диагностика проблем

### Проблема 1: Отсутствие жидкой фазы (КРИТИЧНО)

**Vol P3 = 0** — жидкая фаза полностью отсутствует. Входные растры содержат только `hrelease1` (solid) и `hrelease2` (fine-solid), без `hrelease3` (fluid).

**Почему это критично:** Статья Zhang et al. (2023) о моделировании аналогичного схода ледника Amney Machen в r.avaflow показала, что **без жидкой фазы моделирование провалилось** (Scenario A, SPI < 0.69):

> *"When the debris flow flushing out of the valley entered the broad downstream fan, it diffused toward both sides, reducing the fluid momentum in the centerline"*

Только при добавлении 5% воды (Scenario B, SPI = 0.725) поток канализировался и прошёл по долине. Вода обеспечивает:
- Межфазный drag (вода ускоряет твёрдую фазу)
- Снижение базального трения (поровое давление)
- Канализацию потока (жидкость течёт по руслу, увлекая твёрдую фазу)

**Исторический контекст:** Evans et al. (2009) установили, что катастрофическое снижение эффективного напряжения из-за **избыточного водяного давления** на базе ледника стало причиной отрыва Колки на склоне всего 9°.

### Проблема 2: Завышенное базальное трение (КРИТИЧНО)

**delta1 = 20°** (tan(20°) = 0.364) — стандартное значение для обломочного потока. Для ледникового схода на склоне 6–9° это **физически невозможно**: поток не может двигаться по склону 6° при трении tan(20°) = 0.364.

**Калибровочные данные из литературы:**
| Источник | Событие | Basal friction |
|----------|---------|:---:|
| Evans et al. (2009) | Kolka 2002 | f ≈ tan(6°) ≈ **0.105** (≈ **6°**) |
| Zhang et al. (2023) | Amney Machen, Scenario A | **5°** |
| Zhang et al. (2023) | Amney Machen, Scenario B (solid 1) | **8°** |
| Zhang et al. (2023) | Amney Machen, Scenario B (solid 2) | **6°** |
| Schneider et al. (2011) | Ice-rock avalanches (обзор) | **5–10°** |

### Проблема 3: Завышенная плотность

**density P1 = 2700 кг/м³** — плотность гранита. Ледник Колка = лёд + каменный дебрис, реальная плотность смеси ~1800–2000 кг/м³.

| Материал | Плотность (кг/м³) |
|----------|:---:|
| Чистый лёд | 917 |
| Лёд + обломки | 1200–1500 |
| Обломочный ледник (ice-rich) | 1800–2000 |
| Каменная порода | 2600–2700 |

### Проблема 4: Завышенный угол внутреннего трения

**phi1 = 35°** — типичное для сухого гранулярного материала. Для ледяной массы с водой phi = 25–27° (Zhang et al., 2023; Mergili et al., 2020a).

### Проблема 5: Отключён entrainment

**controls[4] = 0** — вовлечение подстилающего материала выключено. Колка вовлекала огромные объёмы донных отложений и морен по пути движения. Коэффициент вовлечения из литературы: 10⁻⁶ – 10⁻⁸ (Zhang et al., 2023: оптимум 10⁻⁶·⁵).

### Проблема 6: Нет турбулентного трения жидкости

**flufri = 0.05** — очень низкое Manning-число. Для быстрых ледниковых потоков Zhang et al. (2023) использовали **flufri = 3 с²/м** (turbulent friction в модели Voellmy).

### 4.1. Сравнительная таблица

### 4.2. Предлагаемый скрипт r.avaflow

```bash
r.avaflow -e -v prefix=kolka02 cellsize=30 phases=s,fs,f \
  elevation=elev \
  hrelease1=hent1 \
  hrelease2=hent2 \
  hrelease3=<НУЖЕН_РАСТР_ВОДЫ> \
  density=2000,1200,1100 \
  friction=27,6,27,4,0,0,3.0 \
  controls=0,0,1,0,1,0,0,0,0,2,0 \
  basal=-6.5,0.0 \
  time=60,600
```

### 4.3. Проблема с hrelease3 (жидкая фаза)

В текущих входных данных нет растра для жидкой фазы. Варианты:
1. **Создать синтетический растр** — 5–10% от толщины hrelease1, покрывающий ту же область
2. **Использовать hentrmax3** как слой воды — если подлёдная вода есть
3. **Задать через `rhrelease`** — коэффициент от hrelease1

## 5. Сравнение с Башкарой

### Почему Башкара работала корректно:

| Фактор | Башкара | Колка |
|--------|---------|-------|
| Тип процесса | Прорыв озера → сель | Отрыв ледника → ледниково-обломочный поток |
| Жидкая фаза | **hrelease3 задан** (вода) | **hrelease3 отсутствует** |
| Уклон | 15–25° (крутой) | **6–9° (пологий)** |
| Базальное трение | delta=20° адекватно | delta=20° **слишком высокое** |
| Материал | Камни + вода | Лёд + камни + вода |
| Плотность P1 | 2700 (камень) OK | 2700 (камень) **завышена** |

Башкара — это сель с преобладанием воды на крутом склоне. Параметры по умолчанию подходят.
Колка — это ледниковый коллапс на пологом склоне с катастрофическим снижением трения. Нужна специальная калибровка.
